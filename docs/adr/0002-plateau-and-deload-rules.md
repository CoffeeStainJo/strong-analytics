# Plateau Detection and Mesocycle Deload Rules

We decided to define plateau detection using a rolling 3-session stagnation window of Epley-estimated 1RM (e1RM), coupled with a 6-week mesocycle deload tracker and a multi-lift stall trigger. Using Epley e1RM (`weight * (1 + reps / 30)`) standardizes effort across rep ranges (distinguishing true progress from rep shifts). Systemic deload alerts trigger either when reaching week 6 of a training block or when 2+ primary lifts plateau simultaneously, while isolated stalls trigger exercise-specific programming recommendations.
